# Household Account Book

욕망가계부는 일반 가계부와 욕망저금통을 결합한 모바일 앱 프로토타입입니다.

## 현재 포함된 기능

- 지출/수입 기록
- 자주 쓰는 카테고리 아이콘 선택
- 날짜별 지출/수입 달력
- 월별 지출/수입 리포트
- 욕망저금통 프로젝트와 절제 기록
- 카테고리 추가, 삭제, 순서 변경, 아이콘 변경
- Android WebView APK 빌드용 소스

## 실행

```bash
node serve.cjs
```

브라우저에서 `http://127.0.0.1:4174/`로 확인할 수 있습니다.
